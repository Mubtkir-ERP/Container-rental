# نظام إدارة ومتابعة تأجير الحاويات — Container Rental

تطبيق Frappe لإدارة تأجير حاويات نقل الأنقاض/المخلفات، متكامل مع ERPNext.

## المرحلة الأولى — الكيانات الأساسية

- **الحاويات**: رقم فريد لكل حاوية مع **باركود Code128** يُولَّد تلقائيًا + ملصق طباعة جاهز، الحجم (10/20 ياردة)، التصنيف، الفرع، السائق المسؤول، الحالات (متاحة / مؤجرة / تالفة / صيانة / متأخرة / مسحوبة) مع تقييد تغيير الحالة بالأدوار المخوّلة.
- **الموظفون**: بيانات الوظائف الخمس (سائق / مشرف سواقين / خدمة عملاء / متابعة حوالات / إداري)، وثائق الإقامة والتأمين، وحقول السائق (كارت القيادة وعمولة التوصيلة) تظهر فقط لوظيفة سائق.
- **الشاحنات**: اللوحة والنوع والموديل، تواريخ التأمين والاستمارة وكارت التشغيل، متابعة غيار الزيت (تاريخ/كيلومتر)، جدول تراخيص إضافية، وسجل صيانة كامل.
- **الفروع والتصنيفات والخزائن**: خزينة لكل فرع.
- **إعدادات النظام** والأدوار الأربعة بصلاحيات مضبوطة.

## المرحلة الثانية — تكامل العملاء مع ERPNext + دورة الطلبات

- **العملاء = ERPNext Customer** بحقول مخصصة: رقم الجوال (واتساب)، نوع الحساب (نقدي/آجل)، مواقع تسليم متعددة، ورصيد التأجير المستحق — أي عميل يستفيد مباشرة من دورة ERPNext الكاملة، مع زر "إضافة عميل" السريع من شاشة الطلب.
- **تسجيل طلب جديد (S1)**: نوع الطلب (أجل طويل المدى / دفع عند الاستلام / أجل قصير المدى)، اختيار الحاوية يدويًا أو بزر الاقتراح التلقائي من المتاح بنفس الحجم، دعم أكثر من حاوية بالطلب الواحد، مدة وقيمة التأجير مع حساب تاريخ الانتهاء تلقائيًا.
- **دورة حالات الطلب الكاملة**: جديد ← بانتظار تأكيد الحوالة (للأجل القصير فقط) ← بانتظار تحديد سائق ← مُسنَد لسائق ← تم التوصيل / ملغي — بأزرار انتقال مقيدة بالأدوار (خدمة العملاء تؤكد، متابعة الحوالات تعتمد التحويل، مشرف السواقين يُسند السائق والشاحنة).
- **أساس إشعارات واتساب**: تأكيد الطلب للعميل وإسناد التوصيل للسائق (يعمل تلقائيًا عند توفر تكامل واتساب، ويتجاهل الإرسال بأمان عند عدمه).

## التثبيت

```bash
bench get-app https://github.com/Mubtkir-ERP/Container-rental
bench --site <site> install-app container_rental
```
