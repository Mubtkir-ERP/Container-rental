# نظام إدارة ومتابعة تأجير الحاويات — Container Rental

تطبيق Frappe مستقل لإدارة دورة تأجير حاويات نقل الأنقاض/المخلفات كاملة:
استقبال الطلبات، تحديد السائق، التوصيل، متابعة مدة التأجير والتفريغ، الفوترة الشهرية للعقود، والتقارير.

## المكونات الرئيسية

- **الأساسيات**: الحاويات (باركود لكل حاوية)، الموظفون والسائقون، الشاحنات، العملاء، الفروع، الخزائن.
- **العمليات**: طلب حاوية (S1)، تسجيل تعاقد (S2)، تسجيل إيجار (S3)، توصيل، تفريغ (S5)، سحب (S6).
- **المتابعة**: لوحة التحكم (S9)، شاشة الحاويات المتأخرة (S11)، تنبيهات الموظفين (S7) والشاحنات (S8).
- **الفوترة**: فاتورة شهرية تلقائية لكل عقد بعدد الحاويات الموصلة فعلياً، عمولات السائقين، رسوم البلدية.
- **واتساب**: التكامل عبر تطبيق **frappe_whatsapp** — 6 قوالب أحداث (WhatsApp Templates) قابلة للتعديل من لوحة الإدارة، والإرسال والسجل عبر WhatsApp Message (Meta Cloud API). تُضبط بيانات المزود من WhatsApp Settings.

## التثبيت

```bash
bench --site <site> install-app container_rental
```

يتطلب ERPNext v15 وتطبيق frappe_whatsapp.

## افتراضات موثّقة (الأسئلة المفتوحة في وثيقة التحليل)

1. اختيار رقم الحاوية عند الطلب **يدوي** مع زر "اقتراح حاوية" يختار أول حاوية متاحة بنفس الحجم.
2. الطلب الواحد **يقبل أكثر من حاوية** (جدول حاويات إضافية).
3. مدة التنبيه قبل انتهاء الوثائق: **30 يوماً** (قابلة للضبط من إعدادات النظام).
4. **خزينة لكل فرع** (Doctype خزينة مرتبط بالفرع).
5. تغيير حالة الحاوية إلى تالفة/صيانة **مقيّد بدوري مشرف السواقين ومدير الحاويات**.
6. **سحب الحاوية = إرجاعها دون تفريغ** (بلا رسوم بلدية ولا خصم رحلة) وتصبح حالتها "مسحوبة" حتى الفحص، بينما التفريغ يعيدها "متاحة" ويسجل رسوم البلدية.
7. تنبيهات الإقامة/التأمين/الاستمارة **داخل النظام** افتراضياً مع خيار إرسالها واتساب من الإعدادات.
