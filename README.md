# نظام إدارة ومتابعة تأجير الحاويات — Container Rental

تطبيق Frappe لإدارة تأجير حاويات نقل الأنقاض/المخلفات.

## المرحلة الأولى — الكيانات الأساسية

هذا الإصدار يغطي البنية التأسيسية للنظام:

- **الحاويات**: رقم فريد لكل حاوية مع **باركود Code128** يُولَّد تلقائيًا + ملصق طباعة جاهز، الحجم (10/20 ياردة)، التصنيف، الفرع، السائق المسؤول، الحالات (متاحة / مؤجرة / تالفة / صيانة / متأخرة / مسحوبة) مع تقييد تغيير الحالة بالأدوار المخوّلة.
- **الموظفون**: بيانات الوظائف الخمس (سائق / مشرف سواقين / خدمة عملاء / متابعة حوالات / إداري)، وثائق الإقامة والتأمين، وحقول السائق (كارت القيادة وعمولة التوصيلة) تظهر فقط لوظيفة سائق.
- **الشاحنات**: اللوحة والنوع والموديل، تواريخ التأمين والاستمارة وكارت التشغيل، متابعة غيار الزيت (تاريخ/كيلومتر)، جدول تراخيص إضافية، وسجل صيانة كامل.
- **العملاء**: فرد/شركة، جوال، نوع الحساب (نقدي/آجل)، وتعدد مواقع التسليم.
- **الفروع والتصنيفات والخزائن**: خزينة لكل فرع.
- **إعدادات النظام**: مدة التأجير الافتراضية، ومُهَل التنبيهات القابلة للضبط.
- **الأدوار**: خدمة العملاء، متابعة الحوالات، مشرف السواقين، مدير الحاويات — بصلاحيات مضبوطة على كل الشاشات.

## التثبيت

```bash
bench get-app https://github.com/Mubtkir-ERP/Container-rental
bench --site <site> install-app container_rental
```

يتطلب ERPNext v15 (MariaDB).
